COMO PUBLICAR
1. Faça uma cópia de segurança do repositório antes de atualizar.
2. Extraia o ZIP no computador.
3. Envie o conteúdo extraído à raiz do repositório do site, preservando
   exatamente a estrutura das pastas. Mescle as pastas e substitua somente
   os arquivos correspondentes. Não apague as pastas existentes.
4. O index.html solto na raiz do ZIP corresponde à raiz do site.
   Cada outro index.html deve ficar DENTRO da sua respectiva subpasta.
   Não mova os index.html das subpastas para a raiz.
5. Envie também assets/css/dados-empresa.css. As páginas dependem desse
   novo arquivo para apresentar o bloco de identificação.
6. Não envie o ZIP inteiro ao GitHub. Este LEIA-ME não precisa ser publicado.
7. Aguarde a publicação do GitHub Pages e atualize o navegador com Ctrl+F5.
