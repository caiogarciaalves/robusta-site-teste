COMO ATUALIZAR NO GITHUB
1. Extraia este ZIP no seu computador.
2. Abra o repositório do site no GitHub, na mesma raiz onde já ficam o index.html e a pasta assets.
3. Use Add file > Upload files.
4. Envie o CONTEÚDO extraído (index.html, as pastas e este LEIA-ME). Não envie o ZIP nem uma pasta externa envolvendo tudo.
5. Confirme a atualização dos arquivos existentes, mantendo a estrutura de pastas. Faça o commit.
6. Aguarde a publicação do GitHub Pages. Depois abra:
   https://robustaautomacoes.com/politica-de-privacidade/
7. Confira os links no rodapé da home, nas páginas internas, no E-commerce, no Mapa do Pedido e junto ao formulário de Automações.

IMPORTANTE PARA PRESERVAR O SITE
Este é um pacote parcial de atualização. Adicione/substitua os arquivos pelo upload; não exclua o conteúdo do repositório e não substitua toda a pasta assets por uma pasta vazia.
O index.html da raiz continua sendo a página inicial da Robusta. A política fica dentro da pasta politica-de-privacidade.
As pastas do ZIP contêm apenas os HTMLs atualizados e o CSS novo. As imagens, os demais estilos e os scripts já existentes continuam sendo necessários.
Se usar uma ferramenta local para copiar arquivos, escolha mesclar/substituir arquivos, preservando os demais arquivos das pastas.
